# 0.4 运行感知、自动重试、托盘通知与诊断日志验证

验证日期：2026-11-17（Asia/Shanghai）。本机 Linux x86_64、Python 3.14.4、PySide6 6.12.0。

## 新增能力

- **游戏运行感知**：`launch()` 写入 `game-session.json`（PID、可执行路径、命令、代际、时间）。`Engine.game_running()` 以进程存活 + 可执行路径匹配判定运行中；PID 被其他程序复用不误判，脚本包装器通过 `/proc/<pid>/cmdline` 兜底，macOS `open -W` 以等待进程存活判定。运行中引擎拒绝安装与回退，存储层拒绝清理旧安装；GUI 显示“运行中/游戏运行中”，禁用更新、重新安装、回退与旧安装勾选，进程退出后 2 秒内自动恢复。文件校验不受运行状态限制。
- **校验失败一键修复**：校验失败通知挂 `reinstall` 重试，任务区按钮显示“重新安装修复”，确认后走完整重装。
- **下载自动重试**：新增 `NetworkInterrupted` 异常类型标识可重试的传输中断（连接错误、响应截断）。引擎按 2s/8s/32s 退避最多重试 3 次，等待可被取消打断；续传缓存保留进度。SHA-256 不符、HTTP 错误、构建变化保持致命，不重试。
- **诊断日志**：`logbook.py` 向 `logs/updater.log` 追加 JSON 行（安装开始/完成/失败、下载重试、校验结果、回退、启动、清理、目录切换、任务错误），1 MB 轮转保留 3 份备份。逐事件开关文件，不常驻句柄；数据根目录不存在时绝不创建（保持失联目录不重建的约束）。错误详情附日志路径。
- **托盘与通知**：系统托盘可用时提供 显示窗口/检查更新/退出 菜单，单击恢复窗口；窗口不在前台时安装、校验、回退、清理结果发送桌面通知。托盘不可用（如无头环境）时全部静默降级。
- **定时检查与设置**：`settings.json`（与 directories.json 同目录，schema 1）保存定时检查与通知开关；默认窗口打开期间每 4 小时自动检查，可在“关于”页开关。设置损坏静默恢复默认。定时检查不是后台服务。

## 自动化结果

- **94 项回归通过**（0.3 的 80 项 + 新增 14 项）：引擎运行感知与操作防线、PID 复用排除、存活会话判定、瞬断重试续传、重试预算耗尽保留现有安装、logbook 记录/轮转/失联不重建/不可写不抛错、传输中断异常类型、运行中旧安装清理拒绝（缓存仍可清理）、GUI 运行中禁用与恢复、校验失败一键修复、设置持久化与定时检查/通知。
- **16 项 Qt 场景**在 offscreen、Xvfb/xcb 原生窗口、150% 与 200% 缩放全部通过。
- 运行感知测试使用本地 `sleep 30` 合成夹具进程，测试结束只终止自己创建的进程；不下载或运行真实游戏。

## 修复的回归

- 诊断日志最初会在失联目录上重建数据根（扫描失败写错误日志时 `mkdir`），已改为根目录不存在即跳过，`test_unavailable_saved_directory_can_be_replaced_visually` 恢复通过。
- 下载失败日志最初位于事务 try 块之外，已为下载阶段补充 `install_failed` 记录。

## 打包与交付

- `python -m scripts.build` 重新构建 Linux x64 原生包：`dist/RF-Updater-linux-x64.tar.gz` 与 `.sha256` 已更新并通过 `sha256sum -c`。
- 独立包 `--version` 返回 0.4.0；`--root <临时目录> status` 冒烟通过；Xvfb 中打包窗口持续运行（scripts.smoke_native）。
- 安装记录沿用 schema 1，无迁移；0.3 数据目录可直接被 0.4 读取。
