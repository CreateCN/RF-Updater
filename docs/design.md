# 0.2 设计与实现

## 用户确认的方向

深色航天启动器、重新组织布局、PySide6/Qt 原生控件、启动与更新分开。沿用下载和安装引擎，安装记录 schema 1 不迁移。默认窗口 1120×760，最小 900×640，保留系统标题栏。

## 视觉与信息结构

六个基础令牌：背景 `#111D2C`、面板 `#1A2B3D`、文字 `#EDF4FC`、次文字 `#9FB0C4`、强调色 `#58C4E5`、边界 `#30465D`。成功、提示和错误有独立语义色，同时用文字表达状态。字体按系统选择雅黑、苹方或 Noto CJK，不下载字体。

侧栏宽 172；工作区边距 30，页面区块间距 16。显示标题、页面标题、区块标题、正文和注释有统一字号层级。QPainter 绘制小幅轨道与地球示意图，窗口不足 1040 时收起，不使用网络素材或装饰性循环动画。

主页突出当前可以执行的操作，管理页集中目录和维护能力，关于页解释平台、校验范围和社区身份。元数据使用普通文本，长路径可选择复制，详细错误用只读文本控件展开。标准按钮承担全部可交互行为，绘图不承载无障碍按钮。

## Qt 任务模型

`gui.py` 负责页面组装；`ui/theme.py` 管理调色板与样式；`ui/widgets.py` 提供面板、详情、进度和绘图；`ui/controller.py` 管理 worker 与视图状态。

- QObject worker 移入 QThread，结果、异常、进度通过信号进入主线程。进度约 10 Hz 合并，阶段切换和结束立即转发。
- 检查与变更任务分别记录 ID。检查期间允许启动；安装、校验、回退和重复启动串行，执行期间禁用冲突操作。
- 结果必须匹配当前任务标识；过期信号不修改状态。检查错误只清除远端可用信息，保留本地安装和启动能力。
- 沿用 threading.Event 取消，在下载、摘要和解压块之间检查。窗口关闭后禁止新操作，等待现有线程结束，不 terminate 工作线程。
- 工作函数结束时在原工作线程内将 QObject 移回 GUI 线程；QThread 的 finished 信号到达后 wait() 等待本地清理，再由 GUI 线程统一 deleteLater。避免 Qt/Python 包装对象跨线程并发销毁与界面更新间的竞态。
- 自动检查、复制提示使用有窗口父对象的 QTimer，窗口关闭时停止，避免回调访问已销毁控件。

发送启动请求成功只意味着 Engine 已创建启动进程，不显示未经进程观测证实的“正在运行”。游戏本身独立于更新器。安装与回退仍要求玩家退出游戏并备份存档。

## 引擎与信任边界

下载、校验、受限解压与独立代际安装继续使用标准库引擎。安装提交前失败不改变 active；原子提交开始后保留完整的新代，即使替换指针后收到中断也不会删除它。旧安装、缓存和用户写入的数据不自动清理。

HTTPS 保持主机名和证书验证；打包附带 Mozilla CA，不依赖构建机的证书绝对路径。官方提供 SHA-256 时核对，否则以长度和压缩包完整性检查为限。本地文件摘要不等于官方签名。ETag/修改时间不是游戏内版本号，缺少构建标识时不会声称最新。

外部进程环境仅移除打包目录下的 Qt 插件/QML 路径，保留用户路径和主题设置；同时沿用 Linux 的原始 LD_LIBRARY_PATH、Windows DLL 搜索目录和 macOS 路径恢复逻辑。

## 打包与兼容

固定 PySide6 6.12.0；macOS GUI 基线 14，CLI 仍延迟导入图形模块。PyInstaller 自定义 QtGui hook 仅保留桌面平台插件，剔除不使用的图片/文档查看器插件；原生绘图与 PNG 导出不需要 PDF、WebEngine 或 QML。Qt、PySide、Shiboken 和证书许可随包提供。

三平台 CI 先安装运行依赖再执行测试。无显示服务器测试使用 offscreen；Linux 额外通过 Xvfb/xcb 测试实际窗口。高分屏检查以 Qt 的逻辑像素布局进行，截图在实际设备像素下导出。
