- 真实确认对话框中，选择旧安装时“确认清理”最初禁用；只有勾选“退出游戏并完成备份”后才启用。

## 数据与安全边界

- 切换后原安装记录字节不变，原游戏目录与无关文件保留，不执行移动或复制。
- CLI 的显式 `--root` 覆盖保存的位置；无覆盖时使用已记住的目录。配置文件使用唯一临时文件原子替换。
- 目标目录的安装记录字段不完整时拒绝切换，不覆盖已保存位置。
- 已保存目录失联时，读取、安装、校验和回退均不会重建该目录。仍可通过界面切换到其他位置。
- 清理持有数据目录的 OS 锁，并重新读取 active/previous。若选择中任一项目已受保护或不再被识别，在删除任何项目之前拒绝整批操作。
- 缓存按有效构建记录识别，成对清理 `.part` 与其元数据；其他文件、异常记录和链接不提供清理选项。
- 旧安装必须有合法 receipt 且不被 active/previous 引用，并收到明确备份确认。其内部符号链接仅被移除，不遍历到外部目标；外部测试标记文件保持不变。
- 权限失败按项目报告。可能有部分项目已清理，界面刷新后展示剩余项目，不宣称整个批次原子回滚。
- 扫描可取消、限制文件数与列表项数、不跟随链接或 Windows reparse point。统计不完整时限制清理并说明大小只是已读取部分。
- 所有清理验收只操作临时测试目录，没有替用户清理真实缓存、旧游戏或存档。

## 打包与交付

新增目录页沿用深色主题；目录列表与分类图由 Qt Widgets/QPainter 绘制。目录选择器保留 SVG 图标支持，独立包仍排除 WebEngine、QML、QtQuick、QtPdf 与 Tk。

本地构建使用 glibc 2.43；Windows/macOS 构建与原生运行未在本机执行。现有三平台 CI 配置会运行新增测试，但本工作区未上传或执行远程 CI。

独立包 `--version` 返回 0.3.0；使用显式目录成功读取已有真实游戏安装记录。新包在 Xvfb/xcb 中保持实际 Qt 窗口运行，截图见 [bundled-window.png](qa/directories/bundled-window.png)。目录清理只在测试夹具执行，未改动真实游戏记录。

用户级安装器会核对本地压缩包摘要并保留旧程序目录。目录管理设置不随安装程序自动改变；只有用户在目录页明确切换才会保存新位置。原有游戏数据无须迁移。
